# Synthetic datasets

Synthetic datasets are generated task families intended to extend and stress-test ML pipelines for software engineering tasks. They are useful for benchmarking generation quality, translation quality, edge cases, and safety scenarios.

## Best practices

- keep synthetic tasks realistic rather than toy-like
- include clear task types and difficulty tags
- document the generation source and constraints
- validate schema before use in experiments

## Example usage

Synthetic data complements curated processed data by generating broader coverage across languages, edge cases, and prompt variants.
